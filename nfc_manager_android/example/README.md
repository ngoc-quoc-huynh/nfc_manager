# nfc_manager_android_example

A minimal app that calls each `nfc_manager_android` platform method once and
lists the results. For a full demo, see [`nfc_manager/example`](../../nfc_manager/example).

Run it on an Android device with NFC: tap an ISO-DEP tag within 15 seconds.
HCE uses the AID `F000000001` from `android/app/src/main/res/xml/apduservice.xml`.
