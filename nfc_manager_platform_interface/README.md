# nfc_manager_platform_interface

The shared contract between the [`nfc_manager`](../nfc_manager) plugin and its
platform implementations.

## Implement a platform plugin

See the [registration example](example/main.dart) to get started.

## Compatibility

Strongly prefer non-breaking changes (such as adding a method to the interface)
over breaking changes for this package.

See [Flutter's platform interface compatibility guidance](https://flutter.dev/go/platform-interface-breaking-changes).
